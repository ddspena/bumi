# 🌍 Peta Posisi Matahari, Bulan & Waktu Lokal Dunia Aplikasi web interaktif satu file HTML yang menampilkan **posisi Matahari dan Bulan secara real-time** di atas peta **OpenStreetMap**, dilengkapi dengan **area malam**, **terminator siang/malam**, **nama negara + zona waktu**, **hitungan mundur gerhana**, dan **klik peta untuk melihat waktu lokal, hari, dan tanggal** di lokasi mana pun di dunia. Cocok untuk desktop maupun **mobile** — panel dapat dilipat agar peta tetap lega di layar kecil. --- ## ✨ Fitur Utama | Fitur | Keterangan | |---|---| | ☀️ **Subsolar Point** | Titik di Bumi yang saat ini tepat berada di bawah Matahari | | 🌙 **Sublunar Point** | Titik di Bumi yang saat ini tepat berada di bawah Bulan | | 🌓 **Area malam (night side)** | Belahan Bumi yang sedang gelap diarsir biru gelap transparan | | 🟡 **Garis terminator** | Garis kuning pemisah siang dan malam | | 🏳️ **Nama negara + bendera** | Otomatis lewat reverse geocoding, muncul di label peta & panel | | 🕒 **Zona waktu & waktu lokal** | Untuk titik Matahari dan Bulan | | 👆 **Klik peta → waktu lokal** | Ketuk/klik di mana saja → popup menampilkan **jam (berdetak tiap detik), hari, dan tanggal** di lokasi tersebut | | ⏳ **Hitungan mundur gerhana** | Info gerhana terakhir & berikutnya + hitungan mundur real-time | | 📱 **Mobile-friendly** | Panel *bottom sheet* yang bisa dibuka/tutup dengan tap | | 🔄 **Auto-refresh** | Posisi diperbarui tiap **30 detik**, jam popup tiap **1 detik** | | ⏱️ **Timeout API** | Setiap `fetch` punya timeout 10 detik agar UI tidak macet | | 🧪 **Diagnostik** | Panel kecil menampilkan status library & metode perhitungan yang berhasil | --- ## 📁 Struktur Repositori 📁 repo-anda/ ├── 📄 index.html ← aplikasi utama (HTML + CSS + JS satu file) ├── 📄 astronomy.browser.min.js ← library Astronomy Engine (dimuat lokal) └── 📄 README.md ← file ini
